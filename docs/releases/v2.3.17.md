# Mineradio：Windows 2.3.17 / Android 1.1.14

发布日期：2026-10-27。保留 [原项目](https://github.com/XxHuberrr/Mineradio-paused) 署名及 GPL-3.0-only 许可证。

## 本次更新

- 移除音乐库中的“本机已保存的音乐”区块，以及对应列表、按钮、样式和额外曲库读取。
- 音频、歌词、视频导出保留在歌曲下载菜单；预设的保存、下载、导入和加载统一通过“此曲预设”进入。
- 保留账号、歌单、本地音乐、歌词、预设和设置，沿用原有数据格式。
- 本次不调整视频渲染与编码速度。

## 下载与升级

- Windows x64：`Mineradio-2.3.17-Setup-x64.exe`，附 blockmap、`latest.yml` 和 SHA-256，可在软件中检查更新或直接覆盖安装。
- Android ARM64：`Mineradio-1.1.14-release-arm64.apk`，Android 8.0 及以上，沿用原签名，保留完整汽水材料；可在“音乐库 → 检查更新”升级，附 SHA-256。

## 验证与范围

检查桌面导出流程、手机各页面布局及预设菜单迁移，核对歌曲和歌词导出字节、预设导入与加载，以及两端构建资源、安装包和更新文件。

本轮不往手机安装，Android 系统保存与安装弹窗不作为真机验收结论。Windows 包未配置 Authenticode 代码签名。

导出用法见 [视频及预设导出](../VISUAL_EXPORTS.md)。
