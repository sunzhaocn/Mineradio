# Mineradio：Windows 2.3.13 / Android 1.1.10

发布日期：2026-10-26。Windows 修复版；Android 沿用 1.1.10 的同一签名安装包。

## 修复内容

- 修复 Windows 安装升级后仍使用旧网页缓存、右上角更新入口缺失的问题。
- Windows 打包时按网页实际内容生成缓存版本，启动后自动替换旧界面资源，保留账号、本地曲库、歌单与设置。
- 增加缓存版本和构建目录保护回归检查。

## 升级方式

已有更新入口的用户可在软件内更新；如果右上角没有更新入口，请下载 `Mineradio-2.3.13-Setup-x64.exe` 直接覆盖安装一次，安装前无须卸载，也不要清除应用数据。

## 实际验证

- 原版 2.3.11 通过真实更新按钮，从 GitHub 下载并校验 2.3.12，自动退出并完成覆盖安装，重新启动成功。旧缓存导致入口缺失的情况已单独复现。
- 保留触发问题的旧缓存，手动覆盖安装 2.3.13：退出码 0，应用文件与卸载记录版本正确，安装路径不变，旧缓存自动更新，更新入口恢复。
- 覆盖安装期间 3277 个用户数据文件内容均未改变；启动后 28 项本地存储无缺项，其中 27 项内容一致，仅每日推荐缓存正常变化。
- 334 个界面模块加载通过。共享后端 30 项及 Windows 8 项回归通过；Windows/Linux 自动检查见发布提交。

详细步骤与范围见 [Windows 升级验收](../WINDOWS_UPGRADE_VERIFICATION.md)。手动安装测试使用静默参数；结果对应本机环境。Windows 包未配置代码签名，Android 未进行本轮真机安装测试。
