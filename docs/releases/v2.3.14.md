# Mineradio：Windows 2.3.14 / Android 1.1.11

发布日期：2026-10-26。保留 [原项目](https://github.com/XxHuberrr/Mineradio-paused) 署名及 GPL-3.0-only 许可证。

## 本次更新

- Windows 和 Android 直接加载内置页面，移除多余的离线界面缓存及初始化提示。
- 升级启动时自动注销旧页面 Worker，只清理对应的旧页面资源缓存，避免旧界面遮住新功能或更新入口。
- 保留账号、歌单、Cookie、本地音乐和歌词，以及音频、封面、MV 等媒体存储；其他命名缓存不删除。
- 从两端安装包剔除页面 Worker、资源清单及离线初始化脚本，移除原生构建流程中不再需要的页面缓存版本生成逻辑。

## 安装与升级

- Windows x64：`Mineradio-2.3.14-Setup-x64.exe`。已有更新入口可直接在软件内更新；入口缺失时覆盖安装一次，不必先卸载或清空数据。
- Android ARM64：`Mineradio-1.1.11-release-arm64.apk`，Android 8.0 及以上，沿用原签名，可覆盖升级。
- 两个平台均附带 SHA-256 校验文件；Windows 自动更新清单和 blockmap 与同次构建安装包一起发布。

## 验证与范围

Windows 成品从旧版独立测试数据目录迁移通过，334 个页面模块正常加载，账号、歌单和本地音频/歌词测试数据保留，无页面 Worker 或离线提示。真实 Chromium 的 Windows/Android 两种迁移场景通过，其他缓存与 Cookie 保留，已保存的音频仍能播放。

完整构建、自动回归、安装包资源与更新清单检查通过。Android 保留完整汽水材料并延续原签名，ZIP 对齐及 APK 验签通过。本轮暂未安装安卓手机，系统 WebView 的真机升级仍未验收。Windows 包未配置 Authenticode 代码签名。

详见 [迁移验证](../EMBEDDED_UI_CACHE_REMOVAL.md)。
