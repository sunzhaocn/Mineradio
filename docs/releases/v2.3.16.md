# Mineradio：Windows 2.3.16 / Android 1.1.13

发布日期：2026-10-27。保留 [原项目](https://github.com/XxHuberrr/Mineradio-paused) 署名及 GPL-3.0-only 许可证。

## 本次更新

- Windows 新增“导出视频 · 当前预设”：使用所选歌曲和当前/已保存的预设生成带音乐的 MP4，可选 720p/1080p、30/60 帧，支持进度、收起和取消。
- 支持全部 15 个内置预设、MV 与幻灯片，逐帧生成而不占用当前播放器的音频和进度；兼容自定义背景、字体和视频素材。
- Windows 与 Android 本机音乐库可分别导出原音频、LRC 和可重新加载的预设文件；预设可独立关联歌曲、导入、加载，并携带背景、字体、封面及幻灯片素材。
- 下载音频时同时尝试保存当时的预设；后续切歌或更换全局预设不会覆盖此曲记录。
- 修复 Windows 本地媒体通道重复注册导致的读取问题，确保已导入歌曲和封面可用于导出。
- 保留账号、歌单、本地音频、歌词和设置；Android 手机继续轻量模式，视频生成目前由 Windows 完成。

## 下载与升级

- Windows x64：`Mineradio-2.3.16-Setup-x64.exe`，可通过软件内更新或直接覆盖安装，附同次构建的 blockmap、`latest.yml` 和 SHA-256。
- Android ARM64：`Mineradio-1.1.13-release-arm64.apk`，Android 8.0 及以上，沿用原签名，可在 1.1.12 的“音乐库 → 检查更新”下载升级，附 SHA-256。完整汽水材料保留。

## 验证与范围

真实 Electron/FFmpeg 生成 19 段视频，涵盖全部内置预设、高清 60 帧、自定义素材、音画时序、取消、错误处理和文件保留。两端界面与导出字节回归通过，75 项自动回归检查通过。Windows 实际打包程序从 2.3.15 的隔离测试数据升级到 2.3.16 后，账号、歌单、音频、歌词及音乐缓存保留，已导入音频导出字节一致。两端包内资源已与源码核对，APK 原签名、完整汽水材料、16 KiB 对齐及 Windows 更新校验通过。

外部导入的 Wallpaper Engine 工程暂不支持离线视频导出，会明确提示。预设 JSON 不包含外部引擎及完整工程；可在已配置相应项目的 Windows 中载入引用。本轮未往手机安装，Android 系统保存弹窗尚未真机验收。Windows 包未配置 Authenticode 代码签名。

用法、格式、限制与测试证据见 [视频及预设导出](../VISUAL_EXPORTS.md)。
