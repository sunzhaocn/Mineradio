# Mineradio：Windows 2.3.15 / Android 1.1.12

发布日期：2026-10-26。保留 [原项目](https://github.com/XxHuberrr/Mineradio-paused) 署名及 GPL-3.0-only 许可证。

## 本次更新

- 修复手机搜索页右侧大片留白：搜索框、平台切换及结果列表恢复整行宽度。
- 检查首页、音乐库、播放、更多控制、歌单、登录及更新弹窗，覆盖多种竖屏宽度和短横屏。
- Android 新增“音乐库 → 检查更新”：查看正式版本及说明、下载 APK，显示百分比与文件大小，收起后可继续查看进度。
- 下载完成后校验大小、SHA-256、应用标识、版本及原签名，再打开系统安装界面；支持首次来源授权引导、取消后重新安装及失败重试。
- 保留账号、歌单、本地音乐、歌词和设置，继续直接加载内置页面；完整汽水功能构建材料保持。

## 安装与升级

- Windows x64：`Mineradio-2.3.15-Setup-x64.exe`，可在软件内更新或直接覆盖安装，附同次生成的 blockmap 与 `latest.yml`。
- Android ARM64：`Mineradio-1.1.12-release-arm64.apk`，Android 8.0 及以上，沿用原签名覆盖升级。1.1.11 及更早版本需先手动安装本版，之后可使用应用内更新。
- 两端均附 SHA-256 校验文件。Android 安装需要在系统设置中允许 Mineradio 安装应用，最终由用户在系统安装界面确认。

## 验证范围

六种手机尺寸的 Chromium 页面回归、71 项本地自动回归通过，包含实际本地音频/歌词播放及更新界面状态。原生下载与校验代码通过 GitHub 完整文件下载校验；发布构建、安装包资源、签名/对齐和 Windows 更新清单检查通过。Windows 2.3.14 的独立测试数据可由 2.3.15 成品正常读取，账号、歌单、本地音频及歌词测试数据保留。
