# Mineradio：Windows 2.3.12 / Android 1.1.10

发布日期：2026-10-26。基于主分支构建，继续保留 [原项目](https://github.com/XxHuberrr/Mineradio-paused) 署名及 GPL-3.0-only 许可证。

## 下载与升级

- Windows x64：`Mineradio-2.3.12-Setup-x64.exe`。2.3.11 用户可使用右上角的一键更新；更早版本可下载安装包覆盖升级，沿用原账号、歌单和设置。
- Android ARM64：`Mineradio-1.1.10-release-arm64.apk`，支持 Android 8.0 及以上。保持原应用签名，可覆盖升级；安装前无须卸载旧版。
- 每个安装包附带 `.sha256` 校验文件。`latest.yml` 和 `.exe.blockmap` 供 Windows 自动更新使用，不需要手动安装。

## Windows 与共享播放器

- 修复更新检查、下载失败后不能再次重试，以及退出时后台进程和日志清理的问题。
- 统一 QQ、微信和 QQ 音乐 App 登录结果校验，修复微信扫码状态和二维码异常处理。
- 修复媒体跳转时的账号信息转发、退出账号后的音源授权残留，以及音频拖动、断流时的错误处理。
- 移除无效的听歌上报请求，继续保留本地最近播放、歌曲/歌手统计和每日统计。

## Android

- 保留完整汽水签名接入，补齐兼容 SDK 材料的导入、摘要校验和可重复构建流程。
- 修复后台服务重复启动、旧页面销毁影响新页面，以及服务恢复时播放状态丢失的问题。
- 暂停后立即释放唤醒锁，闲置一分钟后退出播放服务，保留通知中的播放入口。
- 封面仅在变化时传递，减少通知和媒体信息重复更新；普通启动避免重复遍历未更新的资源。

## 验证范围

- Windows 完整构建通过，使用独立用户和缓存目录启动成品：334 个界面模块、93 个桌面桥接函数正常加载，后端与桌面进程正常退出；后端模块、加密、二维码及内置浏览器自检通过。
- Windows 打包的 154 个后端模块、524 个网页资源和 21 个桌面脚本与当前源码核对一致；安装包版本、自动更新清单的大小/SHA-512 与实际文件一致。
- Android 正式构建通过，版本为 `1.1.10 / 10110`，原签名证书延续，release 禁用调试；16KiB ZIP 对齐及 APK v2/v3 验签通过。完整的 21 个汽水 DEX 和原生库摘要与导入材料一致，共享网页与 Python 源码一致。
- Windows/Linux 自动回归结果见对应源码提交的 GitHub Actions。发布前核对所有上传文件的 SHA-256 和大小，完整文件到齐后统一公开。

本轮未安装安卓手机，也未完成真实账号授权、汽水运行及锁屏长时间播放的真机验收。系统强行停止或回收整个进程后仍可能中断播放，需要重新打开应用。

本次仅发布 Windows 与 Android 安装包。iPhone/iPad 源码维持现有能力范围，没有新增苹果完整汽水接入、跨设备同步、完整 Spotify 播放、评论发布或平台听歌上报。
