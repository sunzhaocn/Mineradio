# Mineradio Windows 桌面版

2.3.0 新增幻灯片、10 首持久媒体缓存、歌单筛选和本机已保存歌单，修复手机/桌面控制器与榜单切换；MV 自动隐藏开关可用，支持播完回退或循环，搜索框保持居中。逐项验收见 `../docs/播放器修复验收-2.3.0.md`。

2.2.3 修复点击 Home 后 MV 仍显示与播放的问题：主页立即隐藏并暂停视频，音乐继续；回到播放舞台后沿用原视频并同步到当前音乐进度。全浸控制栏的底部唤出保持时间改为约 1 秒，收起动画缩短；鼠标停在控制栏上时继续保持可操作。

2.2.2 修复 MV 遮挡窗口按钮及播放栏自动隐藏；只有全浸模式隐藏界面，底部仍可唤回完整播放栏。MV 卡片下方新增“无 MV 时显示”，可记住其它视觉预设。视频播放期间停绘并隐藏旧粒子场景，减少维护循环与玻璃滤镜开销，缓冲时避免频繁跳转，QQ 默认优先 720p。

Electron 工程在本目录开发、构建和验证；网页与 Python 业务代码共用上层 `web/`、`music_app/`，修复会同时用于网页与桌面版。

成品：`dist/Mineradio-2.3.0-Setup-x64.exe`。首次安装可选择位置；覆盖安装沿用已注册目录，更新同一卸载项和快捷方式。安装后从桌面或开始菜单打开。
软件内置 Electron、Python 后端、Node.js、FFmpeg、登录浏览器兜底和独立汽水签名 SDK，无需另装这些运行环境或汽水音乐客户端。

账号仍由当前客户端本地保存，按请求传给平台；发行包不包含构建机器上的 Cookie、账号文件、日志或缓存。
应用数据保存在 `%APPDATA%/Mineradio`，沿用原有账号和设置。关闭窗口默认进入系统托盘并继续播放，托盘右键可显示窗口或退出；退出会同时结束内置后端。软件设置中仍可改为关闭时直接退出。
托盘右键菜单的“开机自启动”点击勾选即开启，再次点击取消；默认关闭。开启后随 Windows 登录进入托盘。卸载会移除自启动项，并保留用户数据。
四个平台的联网、登录及会员权益仍由对应平台决定。

## 重新构建

构建机需要 Python、Node.js、FFmpeg。汽水 SDK 原文件已经保存在本目录 `sdk/`，重复构建不要求安装汽水客户端。

```powershell
cd Windows_exe
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
```

已有依赖和后端时可使用 `-SkipDependencyInstall -SkipBackend`；`-DirectoryOnly` 只生成 `dist/win-unpacked`，用于快速验证。

```powershell
npm run verify
```

`verification/` 保存隔离测试账号目录、成品启动报告和截图。它们不会进入发行包。
`desktop/` 保留本地音乐、窗口、托盘、快捷键、桌面歌词及 Wallpaper Engine 桥接。
`backend_entry.py` 只负责冻结环境的资源路径、运行依赖及父进程退出监测；业务继续使用上层 `music_app/` 的实现。

Windows 版本为 x64。本地构建未使用商业代码签名证书。

2.3.0 改为本地安装版，提供默认关闭到托盘、后台播放和自启动开关。修复酷狗 Cookie 昵称的百分号 Unicode 编码与过期头像元数据；汽水 Cookie 可直接读取账号资料，读取头像不再要求填写设备编号。旧版保存的手动 Cookie 会重新补齐资料，也可点击“刷新昵称与头像”。桌面播放栏保持一行，为按钮保留独立宽度和间距，窄窗口压缩歌曲信息；一个按钮依次切换列表循环、随机播放和单曲循环，自动混音移至高级设置。

`scripts/verify-installed-app.cjs` 验证自启动开关、窗口关闭后播放进度、启动到托盘及播放栏布局。`scripts/verify-cookie-avatar-ui.cjs` 验证网页与成品四个平台手动 Cookie 的昵称及实际头像加载。

2.3.1 修复手动 Cookie 登录后播放试听音源却被误报为“未登录”的提示，阻止旧登录请求覆盖当前客户端状态，并统一酷狗播放请求对编码 Cookie、复合字段和已知别名的解析。真实试听、会员与歌曲购买限制仍按平台返回处理。

连续切歌会取消旧音源请求，加载中暂停/继续以最后操作为准；旧淡出、预加载、分页和本机输出设备回调不再覆盖新选择。每日精选准备与播放任务分别管理，推荐请求有整体时间预算，部分平台失败时保留其它可用精选，失败后可再次点击重试。还修复了本机歌单重命名、移除后详情刷新和最近播放的本地文件授权恢复。

新建、重命名、删除歌单及短码复制失败时的提示统一使用页面内主题卡片，颜色与玻璃效果跟随外观设置。删除默认聚焦取消，支持 Esc 取消、键盘焦点循环和操作后恢复焦点；不再调用浏览器原生确认或输入弹窗。离线启动先显示本机歌单与收藏，榜单网络超时不会阻塞本机库。

本次自测汇总见 `verification/自测报告-2.3.1.md`，完整功能与未覆盖边界见 `verification/full-audit-feature-matrix.md`。`verification/installer-content-verification.json` 记录最终安装包 SHA256 及内嵌资源与已测成品的核对结果。

2.3.2 合并连续手动选歌，只为最后目标执行播放准备；播放地址先返回，歌词、封面、详情及后续歌曲在后台分批准备。放弃的请求会取消，QQ 配额等待也能退出；已经消耗的平台配额仍按原规则计算。

随心听保留历史与待播队列，前后切换沿用已准备的歌曲，当前音源失败时也能跳过。后台串行预取后续播放地址，只保留一个下一首音频预加载。专辑缺少 ID 时按原生歌曲定位，评论与专辑加载有超时、缓存和重试；评论编码表情正常展示，纯音乐等多余说明已精简。

音乐库移除“四平台合并”虚拟歌单。各平台旁的“同步喜欢”按钮会筛选本机喜欢中的对应平台音源，完整读取平台喜欢并去重，再逐首添加缺少的歌曲。同步支持进度、取消、失败重试和账号切换隔离；取消保留已确认成功的收藏。

2.3.2 完整验证见 `verification/自测报告-2.3.2.md` 和 `verification/full-audit-feature-matrix-2.3.2.md`。安装包可用 `python scripts/verify-installer-content.py` 独立核对，包含内嵌归档 CRC、页面资源及已测二进制 SHA256。

2.3.3 修复原声未关联专辑时的错误提示，专辑请求的网络预算与播放准备等待分别计时。选歌和缓冲时持续显示“音乐加载中…”，暂停、取消或开始播放时自动收起。

每日精选固定为当日本地日期的歌单，沿用最多 30 首规格，同日点击和重新打开不会重新抽取，次日换新。音乐榜单统一入口名称，修复筛选标签被裁切并接入当前主题；音乐库四平台均使用本地官方图标，失效封面自动回退。

本次验证见 `verification/自测报告-2.3.3.md`。

2.3.4 将加载文案移入歌词舞台，音源可播放后才恢复歌词；提前返回的歌词、旧歌词和恢复中的失败源不会闪现。下一首预加载要求真实可解码的媒体数据，提前降档、换同曲音源或跳过确认失败的歌曲，保留超时和账号变化后的重试。

QQ 音质请求合并，减少逐档、逐 GUID 重试对配额的占用；临时失败不当作可长期缓存的无源结果。主动打开专辑立即请求，不再被当前音源解析阻塞。验证详见 `verification/自测报告-2.3.4.md`。

2.3.5 改为右键当场展开歌单并定位视角，取消“先回正、再推近”的等待和两段动画。已有自由镜头、锁定视角或未完成回正会同步退出，卡片直接可见；再次右键仍可关闭，歌曲行右键的下一首操作保持不变。

2.3.6 恢复右键歌单的卡片展开和相机过渡动画，镜头从当前实际视角连续移向歌单。展开与推近同时开始，不再先回正等待后才打开；默认约 0.6 秒，仍按歌单镜头速度设置调整。动画期间再次右键会从当下姿态平滑退出。

2.3.7 在首页推荐前验证真实音频数据可加载、可解码。原来源失败时提前降档或选定同曲的可播平台，并在卡片中显示来源；全平台失败只移除这一首，继续用后续候选补齐推荐。每日精选保留当日候选，刷新、账号和音质变化后重新检查；检查并发受限，不会启动播放或切换当前歌曲。
