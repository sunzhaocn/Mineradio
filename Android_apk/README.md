## 本地运行

APK 内置 Python 3.12、本项目的 `music_app/`、播放器资源、Android 音频容器处理和汽水签名桥。服务仅绑定设备自己的 `127.0.0.1:18000/18080`，无需启动 Windows 电脑或配置云端后端。搜索和播放网络音乐仍需连接各音乐平台。

签名 SDK 在应用自己的 `:sdk` 私有进程中运行。原生异常不会直接终止播放器进程；请求有超时。Android 通过原 NetworkParams 接口生成签名，不运行 Windows 的 `.node` 文件。

汽水扫码使用应用内 WebView 执行与桌面版相同的已固定版本官方安全组件，包含签名校验和安全验证窗口；Android 不依赖 Playwright、Chrome.exe 或 Node。生成二维码已经验证，实际扫码和可能出现的二次验证由用户完成。每次只保留一个汽水安全窗口。

## 原生适配

- 系统文件选择器导入音频、LRC、封面、背景和预设，不申请整个存储空间的访问权限。
- 本地音频、歌词和歌单沿用设备内的 IndexedDB；固定本机端口使重启后仍使用同一存储源。
- 通知栏和 MediaSession 提供暂停、继续、前后切歌及定位；采用 WebView 自身的音频焦点，避免重复抢占。
- 已有媒体解密实现接 Android MediaExtractor/MediaMuxer，AAC/MP4 路径通过自建加密音频的实际解密、重新封装检查。其它编码仍受设备编解码能力限制。
- 浏览器 Blob 下载转为分块本地缓存，再由系统保存对话框选择位置；文件不会经电脑或自建服务器中转。

## 验证范围与限制

真机为连接的 ARM64 Android 手机。平板通过临时调整 Android 显示尺寸和密度验证自动布局选择、WebGL 绘制、后台停止绘制与恢复；没有连接实体平板，不能把该测试当成全部平板硬件兼容性结论。

手机模式检查了模块加载、零 WebGL 渲染、本地音频导入、歌词、播放控制和后台播放。设备内网易云、QQ、酷狗搜索及汽水榜单已返回数据；汽水搜索已适配 Android POST 和 track_wrapper，游客及已登录状态均已返回歌曲。PC Passport 会话被移动搜索拒绝时，仅搜索使用正常的公开目录读取，保存的账号及播放凭据不变。VIP、DRM 和平台权限遵循真实返回，不承诺所有歌曲均可播放。

QQ 云歌单增删已接入适用于 Android 的轻量协议实现，保留设备会话、单次写入和回读确认。真机已完成添加、移除并还原原收藏状态。不同厂商的长时间锁屏播放仍需后续实际验收。

自动验证记录和截图在项目 `runtime/android-build/`。调试版的媒体测试接口、测试音频及 WebView 调试在 release 版本中不可用；release 不接受测试用界面覆盖参数。

## 构建

```powershell
./Android_apk/build.ps1 -Variant debug
./Android_apk/build.ps1 -Variant release
```

构建工具需要 JDK 17、Android SDK 36 / Build Tools 35、Gradle 8.14.3、Python 3.12。[Chaquopy 官方文档](https://chaquo.com/chaquopy/doc/current/android.html)说明 Python 嵌入与 Android 依赖的配置方式。脚本使用独立 ASCII 构建目录，避免 Windows 中文路径造成 Java 工具参数编码问题。

已验证的本机原 SDK 来源位于项目 `runtime/android-portability/com.luna.music-21.3.0/`。构建会保留原 `.so` 和 21 份 DEX 的内容及顺序，记录各自摘要；不会复制电脑的账号配置或运行缓存。不要将此诊断闭包误认为已经裁剪过的最小 SDK 发行包。

`.local/mineradio.keystore` 和 `.local/signing-password.txt` 是后续覆盖升级所需的本机签名资料，均已加入忽略规则。请自行备份，不能丢弃或公开。发布包在构建后追加原始 SDK DEX，再进行 16KiB ZIP 对齐和 APK v2/v3 签名验证。
