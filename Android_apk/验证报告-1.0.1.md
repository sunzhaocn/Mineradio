## 实测范围

手机为连接的 OnePlus PLQ110，Android 17 / API 37、ARM64。手机模式加载 333/333 模块，WebGL 绘制为 0，四个主要导航入口正常。后台实播约 6.5 秒，时间继续前进，系统暂停/继续与封面有效。

平板布局在这台真实手机上临时调整 Android 显示尺寸、密度后验证：自动识别为平板，使用电脑布局和 WebGL 动效，后台绘制增量为 0，返回可恢复；测试结束已恢复原始 1272×2800、560 dpi。**未连接实体平板，不能据此保证所有平板型号的硬件表现。**

交互检查使用可观测的调试构建；最终正式 APK 另做覆盖安装、摘要比对、冷启动、公共搜索/榜单和关闭调试接口检查。Windows 运行检查针对成品 EXE；安装包内全部文件 CRC 检查通过，511 个网页文件与当前源码一致，主要程序文件与被测试的成品一致。

账号状态保留；QQ 写入验证在确认歌曲原先不在目标歌单后才添加，并在结束时移除、回读还原。仅删除本次自建的验证音频；保留实际下载的歌曲、歌词、封面及用户其他曲库数据。

## 使用边界

- 自动保存位置为应用数据中的“本地音乐”曲库。清理应用数据会一并清除；它不等于自动导出至系统公共下载目录。菜单可单独导出 LRC 歌词。
- MV 取决于平台是否提供关联及可用视频地址。汽水音频 ID 不会被误作视频 ID；缺少直接关联时尝试同歌名、同歌手的跨平台候选，找不到或播放失败就用 emily。未宣称每首歌都有 MV。
- 汽水账号的 PC Passport 会话被移动端搜索拒绝时，仅公开搜索可走正常游客目录；账号和播放凭据保留，搜索不会伪装成成功的空结果。
- 短时间真机后台实测通过；不同厂商的长时间锁屏省电策略仍需分别验证。歌曲音质、试听及可播放权限按平台实际返回处理。

机器可读汇总为 `verification.json`。详细证据位于 `../runtime/android-build/` 和 `../Windows_exe/verification/`，其中 `release-installed.json`、`provider-roundtrip.json`、`kugou-cookie-reuse.json`、`offline-download.json` 与 `background-downloaded.json` 对应关键真机流程。
