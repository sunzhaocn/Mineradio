# Mineradio 四平台音乐播放器

这是基于 [XxHuberrr/Mineradio-paused](https://github.com/XxHuberrr/Mineradio-paused) 继续开发的分支，感谢原作者及社区贡献者。原项目名称、设计与既有贡献的署名保留，许可证为 GPL-3.0-only，详见 [LICENSE](LICENSE) 和 [NOTICE.md](NOTICE.md)。

**Windows 最新版：2.3.11** · [下载安装包](https://github.com/sunzhaocn/Mineradio/releases/latest) · [公开源代码](https://github.com/sunzhaocn/Mineradio)

2.3.11 新增一键更新：右上角更新入口可检查 GitHub 正式发行版；点击“立即更新”后显示下载进度，SHA-512 校验通过后自动退出，静默覆盖安装并保留账号、歌单和设置。安装完成后可自行重新打开软件。下载失败不会退出，可在面板重试。旧版尚不具备此功能，需先手动安装一次 2.3.11，此后的版本可在软件内更新。

本仓库只收录音乐播放器源代码，不包含开发机器上的账号凭据、Cookie、个人音乐、运行缓存或测试用户资料。Windows、Android、iOS 和 Web 各自的构建说明见相应目录；iOS 仍需个人签名，真机验证范围见 iOS 文档。


iPhone/iPad 私用测试版：工程与云构建脚本在 `iOS_ipa/`，成品位于 `发布包/iOS私用测试版-20261025/`。已通过 ARM64 IPA 检查、iPad 模拟器启动与 334 个播放器模块加载；需个人签名侧载，汽水尚未接入，实体设备的完整功能待验收。安装方法和详细范围见 `iOS_ipa/README.md` 与 `iOS_ipa/验证报告.md`。

Windows 2.3.0 / Android 1.1.0：新增图片幻灯片、最近 10 首播放资料/封面/MV 持久缓存、歌单筛选和“本机已保存的音乐”；修复手机歌词与更多面板重叠、榜单切换、红心颜色、搜索居中、MV 自动隐藏与结束回退。随心听保留当前歌曲和已预载的下一首，从下下首开始推荐。

本次 31 项需求、验证结果及实际边界见 `docs/播放器修复验收-2.3.0.md`。Windows 安装包为 `Windows_exe/dist/Mineradio-2.3.0-Setup-x64.exe`，Android 安装包为 `Android_apk/dist/Mineradio-1.1.0.apk`。

统一入口是 `main.py`。双击 `启动Mineradio.bat`，或者运行：

```powershell
python -B -X utf8 main.py --open
```

网页为 <http://127.0.0.1:18080/>，音乐 API 为 <http://127.0.0.1:18000/>。
关闭启动窗口或按 Ctrl+C 会统一停止本次启动的服务和登录会话。

Web 与 Windows EXE 共用 `web/` 和 `music_app/`。切歌取消、预加载验源、歌词加载状态、每日精选、随心听、评论、歌单及主题交互均使用同一份实现。浏览器现在也会使用项目内的独立汽水 SDK 和评论图片表情，并在后台检查平台图标与榜单封面。

浏览器导入的本地音频保存在当前站点的 IndexedDB，刷新或重新打开后可以恢复；本机歌单、最近播放会重新取得有效音频地址。文件夹内同名 `.lrc` 可一同导入，网络歌词也会在当前浏览器缓存。音频不会上传到服务端；清除浏览器站点数据会清除这份本地曲库，更换浏览器或访问端口会使用独立存储。浏览器显示文件名和目录信息，EXE 另支持读取嵌入标签。托盘、自启动、桌面歌词浮窗、Wallpaper Engine、系统内存与缓存目录等原生功能在网页中标为桌面版专用。

手机网页仅提供简易播放器，底部为“首页、搜索、音乐库、播放”。不初始化 WebGL 场景或启动特效渲染循环，不运行粒子、3D 歌单、节拍分析和自动混音，跳过启动动画与背景视频；原来通往动效控制台的“设置”导航已移除。音质、淡入淡出、播放模式和歌词校准保留在播放页更多菜单，移动端增益默认 100%，使用系统音量键调节，账号入口仍在右上角，音乐库保留本地导入。桌面网页和 Windows 安装版继续使用原有特效。

```powershell
# 只启动音乐 API，或只启动网页
python main.py --mode api
python main.py --mode web

# 自定义端口，网页会连接指定的 API 端口
python main.py --api-port 18100 --web-port 18180
```

首次安装依赖：`python -m pip install -r requirements.txt`。现有本机环境已经配置好。
汽水音频处理还使用 FFmpeg、Node.js 和签名 SDK；本项目 `Windows_exe/sdk/` 已保留独立 SDK，Windows 安装版内置所需运行环境，无需安装汽水音乐客户端。

Windows 安装版位于 `Windows_exe/dist/Mineradio-2.3.0-Setup-x64.exe`。覆盖安装沿用原目录和用户数据。安装后从桌面或开始菜单打开，关闭窗口默认进入托盘并继续播放；托盘右键可切换“开机自启动”，或选择“退出”彻底关闭程序。右键后歌单展开与镜头推近同时开始，保留连续动画，取消先回正再推近的等待。

## 文件存放

| 目录 | 用途 |
| --- | --- |
| `music_app/api/` | HTTP、参数解析、平台路由、聚合搜索、榜单 |
| `music_app/providers/` | 酷狗、网易云、QQ、汽水各自的请求和歌曲处理 |
| `music_app/auth/` | 手机号、扫码、登录浏览器及短期会话 |
| `music_app/core/` | 请求级 Cookie 隔离、公共字段和缓存 |
| `music_app/web/` | 网页接口、登录桥、下载、媒体代理、HTML 组件展开 |
| `web/player/` | 网页脚本、样式、组件及必要第三方资源 |
| `web/login/` | 独立登录测试页的结构、样式和按职责拆分的脚本 |
| `config/` | 现成下载文件清单及保留的旧配置 |
| `runtime/` | 运行时缓存及日志，可在停止服务后清理 |
| `tests/` | 仍有效的集中回归测试 |
| `docs/` | 接口及模块说明 |
| `third_party/` | 上游版权和许可证 |
| `汽水音乐解密结果/` | 已导出的音频文件，清缓存时保留 |

`main.py` 只负责调用启动器；业务代码不会集中回到入口文件。
应用 Python 模块按职责拆分，前端使用脚本清单独立加载，HTML 按组件清单组装，CSS 按完整规则拆分。
第三方发行包、字体和着色器保留自身资源格式。

## 账号及使用

网页右上角账号按钮支持网易云手机号登录，以及 QQ、酷狗、汽水扫码；进入扫码页或切换扫码方式会自动生成二维码，也可手动重新生成。
四个平台都支持“手动输入 Cookie”。扫码或输入的 Cookie 仅存在当前浏览器的本地存储，点账号即可查看和复制；退出只清除当前浏览器的对应平台 Cookie。手动输入 Cookie 后会读取对应平台的昵称和头像，旧版保存的 Cookie 也会自动补齐资料，并支持手动刷新。服务端不保存登录凭据，不再读取旧的共享账号配置；资料读取失败不清除 Cookie，也不会据此推断会员权限。
每次音乐请求自动携带当前浏览器的 Cookie，API 也支持 `cookie` 参数、`X-Music-Cookie` 或 `Cookie` 请求头；未携带则按游客请求。汽水的设备参数也随请求发送。请求与音源缓存按凭据隔离。
搜索、平台切换、音质、歌词、收藏和现成音频下载保留原接口。
桌面播放栏保持单行，点击播放模式按钮依次切换“列表循环 → 随机播放 → 单曲循环”；自动混音入口位于高级设置。

歌曲详情跟随实际音源显示对应平台的评论，支持文字、表情/图片预览、平台提供的会员/认证标识及分页。
四平台评论均已接入点赞或取消点赞，使用当前平台登录状态；平台未确认操作或评论状态已变化时会明确提示刷新。
汽水评论使用当前浏览器提供的客户端会话，缺少会话或平台读取失败会明确提示，不会误显示成“暂无评论”。
歌词来源显示实际平台；有歌词时可展开查看，纯音乐、歌词未收录和加载失败分别说明，支持重试。

切歌时会按当前歌曲实际可用的档位自动降低音质，保留原来的音质偏好，并显示实际播放音质。媒体链接失效或解码失败时也会尝试低档位。
当前歌曲无源时依次检查网易云、QQ、酷狗和汽水的同曲版本；四个平台均不可播便继续寻找队列中的下一首可播歌曲。整条队列都无源时停止并提示，避免反复循环。
播放期间会静默解析并检查下一首的实际音频数据，确认可解码后才作为预加载缓存；原源失败时优先降低音质或找同曲备用源，确认无可用源则继续检查后续歌曲。下一首和自动切歌会越过本次预检已确认不可播的曲目，全部不可播时有限停止。网络超时保留短期重试，不永久标成坏歌；手动选择歌曲仍能重试。队列、音质或账号变化会释放旧缓存并重新准备。
选歌解析、音频缓冲及同曲恢复期间，歌词区域显示“音乐加载中…”，遮住旧歌词及提前返回的新歌词；音源可播放后再恢复歌词，暂停意图继续保留。取消或最终失败会退出加载，旧歌曲的迟到响应不会影响当前歌词状态。
QQ 必要音质的 vkey 合并为一次请求，逐项核对原生文件名；明确拒绝不再反复变更 GUID 请求，临时网络或服务故障不缓存成永久不可播。平台要求的账号与歌曲权限仍按真实返回处理。
每日精选每次最多 30 首，候选按本地日期保存；同一天重复点击、强制刷新或重开页面不会重新抽取候选，次日生成新候选。展示曲目按当前可播结果从当日候选中补位。网络暂时失败或没有歌曲时可以重试，“今日精选歌单”可查看当天可播曲目。
首页歌曲推荐、每日精选和接下来播放会先静默检查音源能否加载并解码；原来源不可用时先降档或选定同曲可播来源，卡片显示实际播放平台。某首歌全部来源都不可用时只淘汰这首，再从后续候选补位，继续推荐其它可播歌曲。每日候选顺序当天固定，账号、音质变化或检查过期后重新验源；检查不会自动播放或改动正在播放的歌曲。
四平台支持从歌曲封面打开专辑详情，查看专辑资料和有序曲目；大专辑可继续加载更多，曲目可直接加入播放队列。
平台已确认没有关联专辑的音频会明确显示“平台未关联专辑”，不再显示未知专辑和无效重试。播放地址准备与专辑网络请求的超时分别计时。
统一读取接口为 `/album?platform=netease&id=专辑ID`，QQ 也支持 `mid`，分页及凭据说明见 `docs/API.md`。
搜索、队列和歌单的歌手入口支持四平台资料、头像、简介与热门歌曲；旧歌曲缺歌手 ID 时使用同平台歌曲元数据恢复。
统一接口为 `/artist?platform=netease&id=歌手ID`，兼容 `song_id` + `name` 恢复方式；热门目录与平台作品总数分别显示。

首页“我的音乐库”可浏览网易云、QQ、酷狗和汽水的喜欢、收藏及个人歌单；各平台的“同步喜欢”将本机喜欢中的对应音源去重后添加到平台喜欢，支持进度、取消和失败重试。
“隐藏管理”支持整个平台或单张歌单隐藏与恢复，设置保存在当前浏览器，本机喜欢不受隐藏影响。
平台“喜欢”的“导入本机喜欢”会读取全部歌曲并合并到本机“我喜欢的音乐”，保留原有红心，同曲合并并保留全部平台音源；普通歌单仍导入为独立本机歌单，重复导入不会重复创建。
旧版已经导入为独立歌单的“喜欢”会在目录确认其类型后补合并一次，旧歌单继续保留；之后取消本机喜欢不会被自动加回，也可再次主动点击导入补充平台新歌。

单击歌曲红心只加入或取消本机喜欢；长按约半秒（电脑也可右键或 Shift+F10）打开平台歌单菜单。
“最近播放”在歌曲实际开始播放后记录，最多保存 100 首；重复歌曲移至最前，超出后替换最旧记录，刷新页面后仍保留。收听时长和有效播放统计另按实际收听计算。
“收藏到平台歌单”使用对应平台匹配的原版歌曲同步；“从平台歌单移除”先查询实际包含这首歌的可编辑歌单，无匹配时不执行操作。
红心旁的平台圆标表示已查询或同步确认的云端收藏；可同时显示多个平台。
平台同步先检查账号和歌单权限，成功写入后回读确认；失败或未确认会显示原因，普通单击不会触发平台写入。

`config/` 里原有账号文件保留为旧资料，当前请求不会使用这些共享 Cookie。

## MV 播放更新（Windows 2.2.2 / Android 1.0.2）

MV 模式下播放栏保持显示，Windows 顶部帮助、最小化、最大化与关闭按钮可以正常操作。选择全浸模式后隐藏界面，鼠标移到底部或触摸底部可唤回完整播放栏；唤出后短暂保持显示，仍可暂停、切歌和退出全浸。

在 DIY → 常用 → 视觉预设中选择 MV，卡片下方显示“无 MV 时显示”。可选其它 13 种视觉预设，默认 emily；自动记住选择，没有视频或视频加载失败时使用该预设。修改此选项不会重新加载正在播放的 MV。

视频播放期间隐藏旧粒子画面、停止主场景绘制并降低维护循环频率，同时释放被遮住的音域回响网页特效。小幅音画时差通过微调播放速度纠正，拖动进度时立即同步，避免缓冲期间反复跳转。QQ 优先使用 720p 档位，酷狗优先高清档位，降低不必要的解码和网络压力。平台源与设备能力仍决定实际流畅度。

手机继续使用简易播放器；MV 视觉预设在桌面和平板布局中提供。验证记录见 `runtime/mv-controls-verification/验证报告.md`。
